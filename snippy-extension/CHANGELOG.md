# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1] - 2026-10-23

### Added
- Initial release of Snippy extension
- Core orchestration framework for Claude cost optimization
- Ollama-based routing with fallback to local heuristics
- Savings tracking for three cost optimization buckets
- Webview panel for task composition and plan editing
- Status bar item showing savings
- API key management via VS Code SecretStorage
- Configuration settings for main model, Ollama, and pricing
